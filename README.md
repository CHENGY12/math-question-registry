# 数学题批量下载 · 团队台账

本仓库供同事和各自的 agent 共享题号状态，避免下载重复题。题目正文、图片和答案文件保存在团队 Drive；本仓库只保存题号、状态、批次、非敏感别名和文件摘要。

**共享分支：`question-registry`。** 每位操作者都要使用这个远端分支，fork 或本地提交不算领取成功。

## 开始使用

1. 下载[数学题批量下载-同事使用包](releases/math-question-acquisition-kit-2026-11-06.zip?raw=true)并解压，先读包内 `先读我.md`。
2. 在自己的浏览器登录组卷网，确认自己的账号下载权益；使用自己的 GitHub 登录凭据。
3. 仓库公开可读，但写入需要仓库所有者添加 collaborator。没有写权限时，不可跳过领取门槛去下载。
4. 给 agent 指定本次范围、最多下载几批、个人操作者别名和网站账号别名。同一个网站账号共用同一个别名，并且只有一个采集协调者。

## 每批的顺序

准备最多 100 道候选题 → 拉取台账并过滤题号 → 原子领取整批并成功推送 → 登记 downloading → 官方合并下载一次 → 核验原件与题号 → 立即登记 captured。

推送冲突时，更新远端并重新检查题号；不能强推、自动合并旧领取记录，或者只在下载完成后才登记。正在下载的未知结果不可自动释放。

所有领取和状态更新必须使用包内工具。当前未启用服务器分支保护；去重协作依赖所有写入者遵守协议，不手改记录或强制推送。

后续打标、解题思路、公式与图片检查由独立 agent 在本地处理。**整批本地处理完成后才打包上传共享 Drive**，每位同事使用独立的「操作者／批次／版本」目录。Git 领取与下载状态及时更新，不等 Drive 最后上传。

## 已完成的验证

- 2026-11-06：一次官方合并下载 100 题，原件 17,201,093 字节；100 个唯一题号均已核验并登记。
- 原件包含 100 条知识点记录、100 条难度系数；网页额外标签单独保存。
- 已导入此前 5 道样题，共 105 个已下载题号。
- 两个本地并行客户端抢同题时只有一个成功；真实 GitHub 上模拟第二位操作者领取本批 100 题也被全部拒绝。
- Git 题号协作已验证；同事各自的写入权限仍需单独配置。账号下载额度目前由每账号的单个协调者管理，未实现跨机器额度服务。

本次下载结果不代表题目已完成独立数学复核或教师审核。下载规则和账号权益可能变化，使用时以网站实际界面为准。

## 状态

`reserved → downloading → captured → local_ready → archived`

只有下载从未发起的 `reserved` 可以释放。`archived` 需要确认对应版本已经在 Drive 云端出现，仅复制到本地同步目录还不算。

程序、完整流程与测试位于 `math-question-pipeline/`。账户登录资料、Cookie、私有 Drive 链接、真实账号标识和机器路径均不应提交到这个公开仓库。
